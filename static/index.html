Protocol Docs

Integrate TSun Banner Api into your app with a single GET request. No API key required — just drop in a UID.

1 Copy your Free Fire UID (numeric, e.g. 123456789)
2 Call GET /profile?uid=YOUR_UID
3 Receive a ready-to-use PNG banner — no JSON parsing needed
tsun-banner-api
curl -X GET \ "https://tsun-ff-banner-api.vercel.app/profile?uid=123456789" \ --output banner.png import requests url = "https://tsun-ff-banner-api.vercel.app/profile" params = {"uid": "123456789"} r = requests.get(url, params=params) with open("banner.png", "wb") as f: f.write(r.content) print("Saved banner.png") const fs = require("fs"); const https = require("https"); const uid = "123456789"; const url = `https://tsun-ff-banner-api.vercel.app/profile?uid=${uid}`; https.get(url, (res) => { res.pipe(fs.createWriteStream("banner.png")); });
