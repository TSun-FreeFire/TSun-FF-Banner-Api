cURL — Basic Request
curl -L -X GET \
  '/profile?uid=YOUR_UID' \
  -H 'accept: image/png' \
  --output banner.png
cURL — With Overrides
curl -L -X GET \
  '/profile?uid=YOUR_UID&banner=901000001&avatar=902000003' \
  -H 'accept: image/png' \
  --output banner_custom.png
Python — requests
import requests

url = "/profile"
params = {"uid": "YOUR_UID"}

res = requests.get(url, params=params)
with open("banner.png", "wb") as f:
    f.write(res.content)
